# Logos das marcas

Coloque nesta pasta uma imagem para cada marca trabalhada pela loja.

- Formatos aceitos: `.png`, `.jpg`, `.jpeg`, `.webp` e `.svg`.
- Use o nome da marca no arquivo, por exemplo: `bosch.png` ou `ngk.svg`.
- Prefira imagens com fundo transparente.

A faixa da primeira tela encontra automaticamente as imagens desta pasta, ajusta-as sem deformar e faz a rolagem horizontal. Depois de adicionar ou remover uma imagem, reinicie o servidor de desenvolvimento ou gere um novo build.
